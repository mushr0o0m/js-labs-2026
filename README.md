# Лабораторные работы по JavaScript и TypeScript

Нужен Node.js 22.6 или новее. Внешних зависимостей нет.

## Запуск

```bash
npm start
```

Корневой `index.js` последовательно запускает все лабораторные без меню выбора.

| Лабораторная | Отчёт | Отдельный запуск |
| --- | --- | --- |
| Знакомство с ЯП TS/JS | [Отчёт](labs/js-basics/REPORT.md) | `node labs/js-basics/index.js` |
| Пирамидальная сортировка и Priority Queue | [Отчёт](labs/heap/REPORT.md) | `npm run lab:heap` |
| Словарь языка | [Отчёт](labs/dictionary/REPORT.md) | `npm run lab:dictionary` |
