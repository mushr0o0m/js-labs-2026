# Суффиксное дерево и поиск палиндрома

Реализация на TypeScript. Запуск:

```bash
npm run lab:suffix-tree
```

## Суффиксное дерево

Суффиксное дерево - сжатое trie всех суффиксов строки. Рёбра хранят границы участков исходной строки, поэтому подстроки не копируются. Переходы хранятся в `Map`.

Суффиксы добавляются последовательно. При расхождении внутри ребра оно разделяется на общий участок и две ветви. В конец строки добавляется уникальный служебный символ.

Метод `commonPrefix` находит длину общего начала двух суффиксов, проходя по их общим рёбрам.

## Поиск палиндрома

Дерево строится для исходной строки и её разворота с уникальными разделителями. Для каждого центра через `commonPrefix` определяется, сколько символов совпадает справа и слева. Проверяются чётная и нечётная длины, сохраняется самый длинный результат.

При равной длине возвращается первый палиндром слева. Регистр, пробелы и знаки препинания учитываются. Для пустой строки результат пустой.

| Ввод | Результат |
| --- | --- |
| `банан` | `ана` |
| `abba` | `abba` |
| `babad` | `bab` |

## Сложность

n - длина исходной строки. Оценки предполагают O(1) в среднем для обращения к `Map`.

| Операция | Время в худшем случае | Память |
| --- | --- | --- |
| Построение дерева | O(n²) | O(n) |
| Общий префикс двух суффиксов | O(n) | O(1) дополнительно |
| Поиск палиндрома с построением | O(n²) | O(n) |

Для палиндрома дерево строится по `2n + 2` символам, включая разделители. Сумма длин добавляемых суффиксов - `(2n + 2)(2n + 3) / 2`. Узлов не более `4n + 4`, запросов общего префикса - `2n − 1` при n > 0.
